Timer String Builder

Builds the TimerConf string for any BrAiNPlug timer mode — paint a weekly grid, pick times for a daily window, or set an ON/OFF duration cycle.

Schedule grid

Click or drag across the grid to paint when the plug should be on. Each column is one weekday, each row is one hour.

plug on plug off

Note: this grid only paints ranges within a single day. For a range that crosses midnight, generate first, then edit the text below by hand.

Daily on/off window

Same format for both modes — Daily keeps forcing the state the whole time (survives reboot), DailySingle only fires once at each time. Doesn't have to be a same-day range; e.g. 22:00:00-06:00:00 is valid and just crosses midnight.

ON/OFF duration cycle

The plug repeats this ON/OFF cycle continuously — good for pulsing/blinking loads. Not a clock time, this is a duration (HH:MM:SS each).

Generated schedule string

Paste this into the TimerConf field on the plug's web UI, and set TimerMode to match.
