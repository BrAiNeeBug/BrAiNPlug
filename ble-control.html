BrAiNPlug — Bluetooth Control

Controls a BrAiNPlug ESP32 (e.g. Nous A8T) directly over BLE via Web Bluetooth — no app needed. Works in Chrome/Edge on desktop and Android only; iOS Safari and Firefox don't support this API at all. Page must be served over HTTPS (GitHub Pages is fine) — it won't work opened as a local file.

Connection

Not connected

This browser doesn't support Web Bluetooth. Use Chrome or Edge on desktop, or Chrome on Android.

The PIN itself is never sent over the air — the browser computes an HMAC-SHA256 challenge/response locally and only the result goes to the plug. All status reads and writes are locked until that challenge succeeds — an unauthenticated client (e.g. a generic BLE scanner) sees empty/placeholder values.

Timer / schedule

Click or drag across the grid to paint when the plug should be on. Each column is one weekday, each row is one hour.

Note: only paints ranges within a single day. For a range crossing midnight, build first, then edit the string below by hand.

Daily keeps forcing the state the whole window (survives reboot); DailySingle only fires once at each time. Doesn't have to be same-day; e.g. 22:00:00-06:00:00 crosses midnight fine.

The plug repeats this ON/OFF cycle continuously. Not a clock time — a duration (HH:MM:SS each).
